# University Projects TU Graz - Overview

This repository contains a collection of course materials, practical exercises, and assignments focused on Python programming, Machine Learning, and Deep Learning.

## Project Structure

### 1. Python Exercises
Foundational programming and data processing concepts:
* **Core Basics:** Covering data types, control structures, and working with files.
* **Data Structures:** In-depth look at lists, sets, and dictionaries.
* **Object-Oriented Programming:** Implementation of classes and objects.
* **Data Science with Pandas:** Analyzing datasets such as Pokemon and Penguin data using the Pandas library.
* **Assignments:** Comprehensive tasks applying all learned Python concepts.

### 2. Machine Learning Exercises
Implementation and evaluation of classical ML algorithms:
* **Regression Analysis:** Linear and logistic regression models including gradient descent optimization.
* **Supervised Learning:** K-Nearest Neighbors (KNN), Decision Trees, Random Forests, and Support Vector Machines (SVM).
* **Unsupervised Learning:** Clustering techniques like K-Means.
* **Model Training Project:** A full end-to-end project involving exploratory data analysis (EDA), model experimentation, and outlier detection.

### 3. Deep Learning Exercises
Advanced neural network implementations using PyTorch:
* **PyTorch Fundamentals:** Introduction to tensors, automatic differentiation (AutoDiff), and building basic networks.
* **Optimization & Training:** Working with different optimizers, schedulers, and regularization techniques.
* **Computer Vision:** Developing Convolutional Neural Networks (CNNs) for image recognition tasks.

## Setup & Workflow

### Environment Configuration
It is recommended to use a virtual environment for all exercises:

1. **Create Environment:** `python -m venv .venv`
2. **Activate (Windows):** `.venv\Scripts\activate`
3. **Activate (Mac/Linux):** `source .venv/bin/activate`

### Terminal Basics
A central [CHEATSHEET.md](./CHEATSHEET.md) is available in the root directory, providing quick reference for common Git, Terminal, and Python commands.
